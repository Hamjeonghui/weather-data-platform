# 프로젝트 목적

외부 기상 API 데이터를 주기적으로 수집하고,
관리자는 수집 상태를 모니터링하며,
사용자는 수집 데이터를 조회·분석하는 플랫폼을 구축한다.

# 관리자 MVP

- 수집 대상 목록
- 최근 수집 상태
- 성공·실패 건수
- 실패 사유
- 수동 재실행
- 수집 이력 조회

# 사용자 MVP

- 지점별 최신 예보 조회(초단기/단기+중기)
- 특정 기간의 과거 예보 조회(초단기/단기+중기)
- 특정 지점/예보항목의 동일 예측시각에 대한 변화 조회

# 제외 범위

- 관리자 사용자 관리
- 복잡한 알림 설정
- 감사 로그
- 다단계 권한
- 관측값 수집
- 예보값과 관측값을 결합한 오차·정확도 분석
