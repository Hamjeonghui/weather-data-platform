# 사용자 데이터 분석 API

## 1. 예보 지점 목록

사용자가 예보 조회에 사용할 수 있는 지점 목록을 조회한다.

```http
GET /api/locations
```

### 요청 필드

| 필드 | 타입 | 필수 | 설명 | 기본값 |
| --- | --- | --- | --- | --- |
| `keyword` | String | N | 지점명 또는 행정구역 ID 검색어 | 전체 |

### 성공 응답

```http
200 OK
```

```json
{
  "items": [
    {
      "stnId": "11B10101",
      "locationId": "1168000000",
      "stnKo": "서울"
    },
    {
      "stnId": "11H20201",
      "locationId": "2644000000",
      "stnKo": "부산"
    },
    {
      "stnId": "11G00201",
      "locationId": "5011000000",
      "stnKo": "제주"
    },
    {
      "stnId": "11H10701",
      "locationId": "2720000000",
      "stnKo": "대구"
    }
  ]
}
```

### 실패 응답

| 상태 코드 | 코드 | 발생 조건 |
| --- | --- | --- |
| `401` | `UNAUTHORIZED` | 인증 정보가 없거나 유효하지 않음 |

## 2. 지점별 최신 초단기예보 조회

선택한 지점의 최신 발표 시각을 기준으로 현재 이후의 초단기예보를 조회한다. 예보항목을 별도로 선택하지 않고 모든 예보값을 함께 표시한다.

```http
GET /api/forecasts/ultra-short/latest?stnId=11B10101
```

### 요청 필드

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `stnId` | String | Y | 조회할 지점번호 |

### 성공 응답

```http
200 OK
```

```json
{
  "stnId": "11B10101",
  "stnKo": "서울",
  "baseAt": "2026-08-05T14:30:00+09:00",
  "items": [
    {
      "fcstAt": "2026-08-05T15:00:00+09:00",
      "pop": 30.0,
      "rn": 0.0,
      "reh": 68.0,
      "tmp": 31.2,
      "wd": 225.0,
      "ws": 2.4,
      "lgt": 0.0
    }
  ]
}
```

### 실패 응답

| 상태 코드 | 코드 | 발생 조건 |
| --- | --- | --- |
| `400` | `INVALID_REQUEST` | 필수값 누락 또는 요청 형식 오류 |
| `401` | `UNAUTHORIZED` | 인증 정보가 없거나 유효하지 않음 |
| `404` | `LOCATION_NOT_FOUND` | 지점이 존재하지 않음 |
| `404` | `FORECAST_NOT_FOUND` | 선택한 지점에 조회 가능한 예보가 없음 |

---

## 3. 지점별 최신 단기예보·중기예보 조회

선택한 지점의 최신 단기예보와 중기예보를 하나의 연속된 시계열로 조회한다. 단기예보가 제공되는 구간은 단기예보를 우선하고, 이후 구간부터 중기예보를 연결하여 표시한다.

```http
GET /api/forecasts/short-mid/latest?stnId=11B10101
```

### 요청 필드

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `stnId` | String | Y | 조회할 지점번호 |

### 성공 응답

```http
200 OK
```

```json
{
  "stnId": "11B10101",
  "stnKo": "서울",
  "items": [
    {
      "forecastType": "SHORT",
      "baseAt": "2026-08-05T23:00:00+09:00",
      "fcstAt": "2026-08-06T00:00:00+09:00",
      "pop": 20.0,
      "rn": 0.0,
      "reh": 76.0,
      "tmp": 27.0,
      "tmn": 24.0,
      "tmx": 32.0,
      "wd": 210.0,
      "ws": 1.8
    },
    {
      "forecastType": "MID",
      "baseAt": "2026-08-05T18:00:00+09:00",
      "fcstAt": "2026-08-09T09:00:00+09:00",
      "period": "AM",
      "rnSt": 40.0,
      "wf": "구름많음"
    }
  ]
}
```

### 실패 응답

| 상태 코드 | 코드 | 발생 조건 |
| --- | --- | --- |
| `400` | `INVALID_REQUEST` | 필수값 누락 또는 요청 형식 오류 |
| `401` | `UNAUTHORIZED` | 인증 정보가 없거나 유효하지 않음 |
| `404` | `LOCATION_NOT_FOUND` | 지점이 존재하지 않음 |
| `404` | `FORECAST_NOT_FOUND` | 선택한 지점에 조회 가능한 예보가 없음 |

## 4. 특정 기간의 과거 초단기예보 조회

선택한 지점에서 특정 예측 기간을 대상으로 했던 초단기예보를 조회한다. 동일한 예측시각에 여러 발표본이 존재하면 가장 최신 발표본만 표시한다.

```http
GET /api/forecasts/ultra-short/history
    ?stnId=11B10101
    &from=2026-07-01T00:00:00+09:00
    &to=2026-07-07T23:59:59+09:00
```

### 요청 필드

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `stnId` | String | Y | 조회할 지점번호 |
| `from` | OffsetDateTime | Y | 예측일시 검색 시작값 |
| `to` | OffsetDateTime | Y | 예측일시 검색 종료값 |

### 성공 응답

```http
200 OK
```

```json
{
  "stnId": "11B10101",
  "stnKo": "서울",
  "from": "2026-07-01T00:00:00+09:00",
  "to": "2026-07-07T23:59:59+09:00",
  "items": [
    {
      "baseAt": "2026-06-30T23:30:00+09:00",
      "fcstAt": "2026-07-01T00:00:00+09:00",
      "pop": 20.0,
      "rn": 0.0,
      "reh": 75.0,
      "tmp": 24.5,
      "wd": 180.0,
      "ws": 1.5,
      "lgt": 0.0
    }
  ]
}
```

### 실패 응답

| 상태 코드 | 코드 | 발생 조건 |
| --- | --- | --- |
| `400` | `INVALID_REQUEST` | 필수값 누락, 조회 기간 오류 또는 요청 형식 오류 |
| `401` | `UNAUTHORIZED` | 인증 정보가 없거나 유효하지 않음 |
| `404` | `LOCATION_NOT_FOUND` | 지점이 존재하지 않음 |
| `404` | `FORECAST_NOT_FOUND` | 선택한 지점 또는 기간에 조회 가능한 예보가 없음 |

## 6. 동일 예측시각의 예보 변화 조회

특정 지점과 예보항목의 동일한 예측시각에 대해 발표 시점별 예보값 변화를 조회한다. 실제 관측값과 비교하는 정확도 평가는 포함하지 않는다.

```http
GET /api/forecasts/changes
    ?stnId=11B10101
    &forecastType=SHORT
    &forecastItem=TMP
    &fcstAt=2026-08-07T12:00:00+09:00
```

### 요청 필드

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `stnId` | String | Y | 조회할 지점번호 |
| `forecastType` | String | Y | 예보 구분(`ULTRA_SHORT`, `SHORT`, `MID`) |
| `forecastItem` | String | Y | 조회할 예보항목 코드 |
| `fcstAt` | OffsetDateTime | Y | 비교할 예측일시 |

### 성공 응답

```http
200 OK
```

```json
{
  "stnId": "11B10101",
  "stnKo": "서울",
  "forecastType": "SHORT",
  "forecastItem": "TMP",
  "unit": "℃",
  "fcstAt": "2026-08-07T12:00:00+09:00",
  "items": [
    {
      "baseAt": "2026-08-06T06:00:00+09:00",
      "value": 29.0
    },
    {
      "baseAt": "2026-08-06T18:00:00+09:00",
      "value": 31.0
    },
    {
      "baseAt": "2026-08-07T06:00:00+09:00",
      "value": 30.0
    }
  ]
}
```

### 실패 응답

| 상태 코드 | 코드 | 발생 조건 |
| --- | --- | --- |
| `400` | `INVALID_REQUEST` | 필수값 누락 또는 요청 형식 오류 |
| `400` | `INVALID_FORECAST_ITEM` | 예보 구분에서 지원하지 않는 예보항목을 요청함 |
| `401` | `UNAUTHORIZED` | 인증 정보가 없거나 유효하지 않음 |
| `404` | `LOCATION_NOT_FOUND` | 지점이 존재하지 않음 |
| `404` | `FORECAST_NOT_FOUND` | 선택한 조건에 해당하는 예보 이력이 없음 |
