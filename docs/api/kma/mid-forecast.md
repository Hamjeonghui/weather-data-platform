# 기상청 중기예보 API

## 기본 정보

- 공식 문서:
  https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=FILE_000000003562282&fileDetailSn=1
- 확인일: 2026-08-11
- Base URL: `https://apis.data.go.kr/1360000/MidFcstInfoService/getMidLandFcst`
- 인증 환경변수: `kma.service-key`
- 제공 범위: 최근 24시간 발표자료

## 사용 파라미터
| 외부 필드 | 타입/형식 | 필수 | 설명 | 값 결정 방식 | 내부 출처 | 예시 |
|---|---|---:|---|---|---|---|
| `serviceKey` | String | Y | 공공데이터포털 인증키 | 환경변수에서 읽음 | `kma.service-key` | 실제 값 미기재 |
| `pageNo` | Integer | Y | 페이지 번호 | `1`부터 시작 | 수집 로직 | `1` |
| `numOfRows` | Integer | Y | 페이지당 결과 수 | 프로젝트 고정값 | 애플리케이션 설정 | `10` |
| `dataType` | String | N | 응답 데이터 형식 | `JSON` 고정 | 애플리케이션 설정 | `JSON` |
| `regId` | String | Y | 중기육상 예보구역코드 | 지점에 연결된 광역 예보구역코드 사용 | `location_info.reg_id` | `11B00000` |
| `tmFc` | String, `yyyyMMddHHmm` | Y | 발표시각 | 최근 유효 발표시각 계산 | 수집 스케줄러 | `202608110600` |
> `regId`는 단기예보 격자나 시·군 지점코드가 아니라 중기육상예보 구역코드를 사용한다.

## 응답 필드 매핑

중기육상예보 응답을 `예보일 + 시간구분`별 행으로 변환한다.

| 외부 필드 패턴 | 적용 범위 | 내부 컬럼 | 예보일 계산 | `period` |
|---|---|---|---|---|
| `rnSt{day}Am` | `{day}` = 3~7 | `rn_st` | 발표일 + `{day}`일 | `AM` |
| `rnSt{day}Pm` | `{day}` = 3~7 | `rn_st` | 발표일 + `{day}`일 | `PM` |
| `wf{day}Am` | `{day}` = 3~7 | `wf` | 발표일 + `{day}`일 | `AM` |
| `wf{day}Pm` | `{day}` = 3~7 | `wf` | 발표일 + `{day}`일 | `PM` |
| `rnSt{day}` | `{day}` = 8~10 | `rn_st` | 발표일 + `{day}`일 | `DAY` |
| `wf{day}` | `{day}` = 8~10 | `wf` | 발표일 + `{day}`일 | `DAY` |

- 요청에 사용한 `tmFc`를 `base_at`으로 저장한다.
- 필드명의 `{day}`와 시간구분을 이용해 `fcst_at`을 계산한다.
- `regId`에 대응하는 내부 지점을 조회해 `location_id`를 설정한다.
- `base_at`, `fcst_at`, `period`, `location_id`가 같은 `rnSt`와 `wf`는 한 행으로 병합한다.

## 발표시각 결정 규칙
- 발표시각은 매일 `06:00`, `18:00`이다.
- 모든 계산은 `Asia/Seoul`을 기준으로 한다.
- 실행시각 이전의 가장 최근 발표시각을 `tmFc`로 사용한다.
- 발표 직후 조회에 실패하면 일정 시간 후 같은 발표시각으로 재시도한다.
- 자료 미생성이 확인되면 직전 발표시각으로 다시 조회한다.
- 요청에 사용한 `tmFc`를 내부 `base_at`으로 저장한다.
- 
### 예측일시 계산 규칙
1. 기준 날짜는 `base_at`을 `Asia/Seoul`로 변환한 날짜로 한다.
2. 외부 필드명의 일수 `{day}`만큼 기준 날짜에 더한다.
3. 시간구분별 대표시각은 다음과 같이 지정한다.

| `period` | 대표시각 | 의미 |
|---|---:|---|
| `AM` | `00:00:00+09:00` | 해당일 오전 구간의 시작 |
| `PM` | `12:00:00+09:00` | 해당일 오후 구간의 시작 |
| `DAY` | `00:00:00+09:00` | 해당일 전체 |

4. 대표시각은 정렬과 조회를 위한 내부 기준값이며 실제 기상현상의 발생시각을 의미하지 않는다.

## 발표 시각
- Base_time : 0600, 1800 (1일 2회)

## 수집 규칙
- 같은 발표본의 `rnSt`와 `wf`는 예보일과 시간구분이 같으면 한 행으로 병합한다.
- 동일한 `location_id`, `base_at`, `fcst_at`, `period` 조합은 중복 저장하지 않는다.
- 재수집 시 동일 식별키의 기존 레코드를 갱신한다.
- 응답값이 없거나 `null`이면 해당 컬럼을 `NULL`로 유지한다.
- 정의되지 않은 응답 필드는 저장하지 않고 경고 로그를 남긴다.
- 발표시각에 따라 일부 예보일 필드가 제공되지 않을 수 있으며, 값이 없는 필드는 내부 컬럼을 `NULL`로 유지한다.
