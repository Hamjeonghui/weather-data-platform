# 기술 스택

## Backend

- Java 17
- Spring Boot 3.5.4
- Spring Data JPA
- Spring Security
- PostgreSQL

## Frontend

- React
- TypeScript
- Vite

## Infrastructure

- Docker Compose
- PostgreSQL 17
- 추후 AWS EC2, RDS(미정) 적용 예정

# 로컬 실행 구조

React와 Spring Boot는 로컬에서 실행한다.
PostgreSQL만 Docker Compose로 실행한다.

React → Spring Boot → Docker PostgreSQL
